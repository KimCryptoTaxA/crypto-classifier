Crypto Transaction Classifier

Checks which blockchains your wallets are active on, pulls their history live from block explorers, classifies each transaction (DeFi, swap, NFT, bridge, staking, transfer, scam/spam), and exports a CoinTracking-style Excel file.

2. Blockchains & explorers to check

Bridge / NFT / DeFi explorers — add detail to matching transactions

3. API keys (optional — each unlocks specific chains/explorers)

Each key is sent only to its own service (helius, opensea, zerion, blockscout, etherscan, debank). The Blockscout key, Bitcoin xpub/zpub and Cardano need the local helper: run python3 start-classifier.py.
